# 归因 ⑨：pinky_abad 超限，是这个关节读数异常/跳变了？

> **结论：❌ 被否定。** 连续 8 次采样稳定在 -0.186104，读数非常干净。问题不在数据，在"标准"。

## 1. 观测（看到了什么）

- read 服务报错：
  ```
  left joint 8 (pinky_abad) value -0.1861 below limit -0.1850
  ```
- 翻译：小指根关节读数 -0.1861，低于配置下限 -0.1850，被限位检查拦下。

## 2. 推测（猜了什么 · 为什么这么猜）

**猜测：这个关节的读数异常/跳变了。**

理由：读数"低于限位"，第一反应是传感器读数漂了、或者偶发毛刺。

## 3. 验证（怎么证明这个猜测）

- 对同一个关节**连续采样 8 次**，看读数稳不稳定。
- 如果读数跳变 → 数据问题；如果读数稳定 → 数据没问题，是"标准"问题。

## 4. 结果（验证怎么说）

- ❌ 连续 8 次采样：**全部稳定在 -0.186104**，小数点后四位都不动。
- ❌ 读数非常干净，没有毛刺、没有漂移。

```
采样：-0.186104  -0.186104  ...  -0.186104  ← 8 次完全一致
```

## 5. 结论与教训

**数据没坏，是"标准"定错了。** 读数稳定 ≠ 读数合法——还要看"合法范围"定得对不对。

> 教训⑨：**多次采样区分"数据坏"还是"标准错"。** 连续采样稳定，就该把怀疑从传感器移到限位配置上。
