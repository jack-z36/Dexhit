# O10 设备自动绑定与探测（单手引导 → 双手自动）

目标：两只 OmniHand O10 的 USB CANFD 适配器随便插哪个 USB 口，`./start_omnihand_control.sh --sides X` 直接能跑。身份锚是手的出厂序列号（`VendorInfo.product_seq_num`，CAN 可读、不随插拔变化）；`canfd_device_id` 是 SDK 每次扫描的临时枚举，由启动时发现机制现查。绑定文件存 **side → serial**，永不存索引；"右手默认 0、左手默认 1"保留为接线惯例与兜底默认值。

范围边界（本期不做）：运行中热插拔自愈；`launchpad/default.yaml` 平行启动路径改造；手势辨识仪式；任何 git 提交。

## 冻结契约（T02/T03/T04 依赖此节，实现必须逐字对齐）

### 绑定文件

- 位置：worktree 根 `o10_hand_binding.json`（根 `.gitignore` 追加一行）。
- Schema：`{"left": {"product_seq_num": "...", "bound_at": "<ISO8601>", "bound_by": "auto|bind"}, "right": {...}}`；某侧未绑定时省略该键。
- 损坏容忍：JSON 解析失败或结构非法 → 视为空表并在 stderr 警告，不崩溃。

### CLI `omnihand_o10_probe`（console_script，模块 `omnihand_o10_hardware_adapter.probe`）

- `scan [--max-index N] [--recv-timeout-ms MS]`：扫描索引 0..N（默认 N=3），每索引按 `hand_device_id=1, canfd_channel_id=0, transport=hcan` 构造手。**在线判定必须靠 `get_vendor_info()` 的 `product_seq_num`/`dof` 非空 + `get_all_joint_positions()` 非空**（open/init 成功不算——SDK 对越界索引也不抛）。stdout 输出 JSON 数组 `[{"canfd_device_id": 0, "hand_online": false, "product_seq_num": null, "dof": 0}, ...]`；人类可读过程信息走 stderr。默认 recv 超时 200ms，总预算 <5s。
- `resolve --sides {left|right|both} [--file PATH] [--max-index N] [--recv-timeout-ms MS]`：扫描后按决策规则解析，成功时 stdout 输出可 `eval` 的行 `OMNIHAND_O10_LEFT_CANFD_DEVICE_ID=<idx>` / `OMNIHAND_O10_RIGHT_CANFD_DEVICE_ID=<idx>`（仅被解析的侧）；决策过程（含自动绑定落盘）打 stderr。失败 exit 1。
- `bind --side {left|right} [--file PATH] [...]`：要求**恰有一只手在线**，读其序列号登记为该侧并落盘；0 只或 ≥2 只在线时报错并指引（无手势仪式、无确认步——用户已选直接落盘）。
- 环境隔离：缺 `DEXHIT_COLLECTION_PREFIX` → stderr `BLOCKED_ENV: ...` exit 2；SDK wheel 缺失 → `RuntimeError("Agilink O10 SDK wheel is not installed")`（与 backends.py 同文案）。`main()` 不得在 import 期触碰 SDK。

### resolve 决策规则（冻结，逐条实现）

1. 已绑定侧：其序列号本次在哪个索引上被发现 → 该侧用那个 `canfd_device_id`。
2. 自动绑定（排除法）：某请求侧未绑定 + 恰有一条未知序列号的在线总线 + 恰剩这一个空位 → 登记为该侧并落盘（`bound_by: auto`），stderr 醒目打印 `已自动绑定: <side>=<serial>`。
3. 未绑定但无法唯一排除（两条在线总线序列号都未知；或两侧都未绑定时双手同时在线）→ 中止 exit 1，stderr 提示"只保留一只手在线并运行 `omnihand_o10_probe bind --side <side>`"。
4. 0 手在线 → exit 1，stderr"未发现任何在线的手：检查电源与 CAN 线"。
5. 已绑定序列号本次未扫到且该侧被请求 → exit 1，stderr 明确报该侧手掉电/拔线。
6. `--sides both` 但某请求侧无在线手 → exit 1，报缺哪只。
7. 请求侧之外的总线/手：不解析、不绑定（`--sides right` 不动 left 的任何状态）。
