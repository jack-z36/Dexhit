## 全局执行入口

构建、安装、日志和测试结果必须在工作区外的临时目录生成：

```bash
source /opt/ros/jazzy/setup.bash
TEST_ROOT="$(mktemp -d /tmp/dexhit-collection-test.XXXXXX)"

colcon --log-base "$TEST_ROOT/log-build" build \
  --merge-install \
  --base-paths src/collection/omni_hand \
  --build-base "$TEST_ROOT/build" \
  --install-base "$TEST_ROOT/install" \
  --cmake-args \
    -DPython3_EXECUTABLE=/usr/bin/python3.12 \
    -DPYTHON_EXECUTABLE=/usr/bin/python3.12

colcon --log-base "$TEST_ROOT/log-test" test \
  --merge-install \
  --base-paths src/collection/omni_hand \
  --build-base "$TEST_ROOT/build" \
  --install-base "$TEST_ROOT/install" \
  --test-result-base "$TEST_ROOT/test-result"

colcon test-result --test-result-base "$TEST_ROOT/test-result" --verbose
```

需要 Pinocchio、NLopt 或正式 SDK 时，使用工作区外的 Miniforge/mamba 环境。依赖下载顺序是先尝试国内镜像；镜像失败后才使用 Fclash `127.0.0.1:7890`。当前验证环境为 Python 3.12、Pinocchio 4.1.0、NLopt 2.11.0 和 Agilink `omnihand` 1.1.8。

## 证据边界

已通过的自动化测试不等同于现场验收。以下事项仍明确未验证：

- 真实 Rokoko Studio 脱敏 UDP 抓包与目标现场兼容性；
- 真实 O10 factory、反馈物理语义、命令动作和硬件错误位；
- watchdog、速度舒适性、通信时序和真机安全参数标定；
- 模型资产许可确认及正式 vendoring。

因此后续报告必须分别写“自动化/无真机通过”和“现场或真机未验证”，不能合并成硬件通过。
