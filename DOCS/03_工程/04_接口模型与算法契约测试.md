# 接口、模型与算法契约测试

更新时间：2026-08-14

## 文档职责

本文只记录跨包 wire contract、共享值对象、模型资产和重定向数学的可重复契约测试。字段语义以 [Rokoko RawHandFrame 契约](../01_知识/04_Rokoko原始手部帧ROS接口契约.md)、[RetargetingState 契约](../01_知识/05_手部重定向状态ROS接口契约.md)、[O10 状态契约](../01_知识/06_O10控制状态ROS接口契约.md)、[控制操作契约](../01_知识/07_O10操作者控制操作ROS接口契约.md) 为准，本文不复制完整 schema。

## T01：wire contract smoke

T01 的验收必须使用一次性干净的 ROS build/install 空间，不能让旧生成代码掩盖 `.msg/.srv` 变化。检查重点为：

- `RetargetingState` 使用数组式逐指状态，并用 `length_state` 表达冻结事实；不保留独立整体 `FROZEN` 阶段；
- `O10ControlState` 的事件、阶段、目标结果、fault 位、hardware error 数组和时间字段与权威契约一致；
- `ControlOperation.srv` 的 clear_fault 结果码（`4fedfaa` 起 arm/disarm 已移除）只由接口包提供；
- Application 只使用字符串或 `auto()` 语义，ROS Adapter 通过生成消息常量映射；
- 删除旧的嵌套 `FingerRetargetingState` wire 用法，不维护双 schema 兼容层。

## T02/T03：共享契约与资产边界

T02 测试确认纯契约包不 import ROS、模型、Pinocchio/NLopt、厂商或测试代码。T03 测试确认模型包不把开发者绝对路径写入生产加载路径；许可未确认时只使用固定 commit 的外部只读资产，不复制进仓库。

当前真实资产 provenance 固定于外部 `ManusOmniBridge` commit `f4fd0d913c2151bcb4be0d29fbc02761b9638009`。该来源、文件哈希和模型结构是测试输入，不是仓库内的资产副本。

## T05：归一化与状态契约

T05 的契约测试覆盖以下不可替代的边界：

- 未完成五指长度冻结前不发布软目标；
- 五指冻结后直接进入 `WAITING_FIRST_VALID_IK`；
- 未执行 IK 的字段使用 NaN/availability 语义，而不是伪造零值；
- 单指冻结异常、掌坐标退化和模型错误按规定隔离到同侧；
- 左右 session 的历史、阶段和恢复进度不共享可变对象。

## T06：真实数值验证

真实数值测试只在工作区外 mamba 环境执行，并通过 `OMNIHAND_O10_MODEL_FIXTURE` 指向外部固定资产。环境管理要求：

1. 使用 Miniforge 中的 mamba，不在仓库内创建环境；
2. 先尝试国内镜像；
3. 镜像失败后使用 Fclash `HTTP_PROXY/HTTPS_PROXY=http://127.0.0.1:7890`；
4. 通过 `/usr/bin/python3.12` 与 ROS Jazzy 安装空间运行测试；
5. 记录 Pinocchio/NLopt 版本和外部资产 commit，避免把环境偶然性写成算法证据。

验收是左右两侧、五指和耦合差异均覆盖的中心差分比较。测试通过证明解析梯度与固定资产在当前样本上的数值一致；不证明真实手指机构、执行器误差或现场舒适性。
