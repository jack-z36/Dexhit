# 03 — 前端方块网格页

**Spec:** [08_Launchpad 网页一键启动遥操作系统 Spec](../../08_Launchpad网页一键启动遥操作系统Spec.md)

**What to build:** 操作者在浏览器中完成启动配置与运行控制：模式模板按钮（真机/数据链路/全链路 sim）一键预点亮对应方块，方块可自由增删；启动前网格是配置，启动后点击方块即启动/停止该进程，网格持续显示期望状态与实际状态（期望亮但进程死为红闪）；侧别选择器与关键参数（UDP 端口、actor 序号、CAN 通道）可编辑。校验规则的 UI 完整呈现：硬阻止弹窗、危险组合红横幅与二次确认、混流与孤儿黄提示、停止方块的下游影响提示。业务节点方块与工具方块（sim provider、合成输入源、录制器）视觉区分，全中文。配合替身进程可完整演示"选模板 → 增删方块 → 启动 → 停单节点 → 全停"一轮。

**Blocked by:** 02 — 编排核心：期望状态与替身进程。

**Status:** ready-for-agent

- [ ] 三个模式模板按钮正确预点亮对应方块集合
- [ ] 方块点击增删生效；运行中点击即启停该进程，期望 vs 实际差异红闪呈现
- [ ] 侧别选择器与关键参数可编辑并随启动提交
- [ ] 硬阻止、红横幅二次确认、黄提示按校验规则呈现
- [ ] 停止方块时显示下游影响提示
- [ ] 业务节点与工具方块视觉区分；UI 全中文
- [ ] 以替身进程为对象完整演示配置→启动→单节点启停→全停一轮（截图或 E2E 证据）
