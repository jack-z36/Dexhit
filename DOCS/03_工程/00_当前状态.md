## 当前判断

Rokoko → OmniHand O10 全链路已经能**真机运行**：佩戴 Rokoko Smartgloves 可驱动实体灵巧手。控制链的 `arm`/`disarm` 操作者门控已在 `4fedfaa` **整体移除**（运动由新鲜合法软目标直接驱动，对齐官方 Agilink SDK 直控行为），只保留 `clear_fault` 操作 Service。Launchpad 网页控制面已完成 T01 骨架与两个前端版本。当前主要问题集中在**运动质量问题**：大拇指能运动但很慢，四指无法正常屈伸（只能左右移动）。

## 已验证（截至 `4fedfaa`）

### 全链路真机

- 手套 → 接收 → 重定向 → 控制 → 真机手运动链路已跑通；`fake_left_command`/真手套驱动实体手出命令、关节反馈流动。
- 四类叠加问题已修复并真机复验：SDK 批量错误接口 bug、`commu_except`（bit4，厂商历史标记）被误当致命故障锁存、provider 从不发布反馈、control 转发的命令缺 `name` 字段（见 [O10 调试复盘](../99_learning/O10调试复盘/INDEX.md)）。
- `commu_except`（bit4）不再作为锁存故障依据：只有 `FATAL_ERROR_BIT_MASK`（bit0–bit3：stalled/overheat/over_current/motor_except）任一非零才锁存 `HARDWARE_ERROR`；`hardware_error_bits` 保留原始错误字（含 bit4）供诊断（ADR-0005 修订）。

### 控制语义变更（`4fedfaa`）

- 移除 `armed`/`arm`/`disarm`；`motion_enabled = feedback_ready ∧ error_monitor_ready ∧ target_ready ∧ target_fresh ∧ ¬fault_latched`。
- 阶段枚举改为 `INITIALIZING / IDLE_NOT_READY / IDLE_READY / ACTIVE / PAUSED_TARGET_STALE / FAULT_LATCHED`。
- 操作者唯一 Service 是 `/o10_control/{side}/clear_fault`；`ControlOperation.srv` 只含 clear_fault 结果码。
- ADR-0004（逐侧显式授权）已标记 superseded。

### 既有自动化与门禁

- T01–T11 无真机验证此前已通过（socket、模型、接收、重定向、控制、系统测试、架构门禁 A01–A22）；`4fedfaa` 起门禁扩展 A23/A24（Launchpad 骨架边界与真机不引用 `system_test`）。
- 10 个 ROS 包可在工作区外临时 build/install 空间干净构建；最近一次全包 `colcon test` 为 278 个 colcon 测试项、0 failures、0 errors、2 skips。
- Launchpad 单实例锁、T01 FastAPI/uvicorn 入口、前端脚手架与占位首页已落地（见 [ADR-0011/0012](../01_知识/ADR/INDEX.md) 与 [08 Launchpad Spec](08_Launchpad网页一键启动遥操作系统Spec.md)）。

## 已知问题（下一优先）

- **大拇指能运动但很慢**：拇指动作幅度与速度不及四指，需排查重定向（拇指 DIP 耦合/IK）、限速配置或真机限位。
- **四指无法正常屈伸，只左右移动**：四指（index/middle/ring/pinky）目前主要只出 abad（左右）分量，pip（屈伸）几乎不动——疑似重定向目标、单指 IK 或软目标/命令映射问题，是当前最核心待查问题。
- 真机 watchdog、通信时序与安全参数数值、速度舒适性仍未做正式标定。
