# 07_真机IK残差失败判别报告

> 2026-08-17。回答"Rokoko 手套原始数据经重定向节点处理后为什么不出 `/o10_control/left/command`"的判别问题：在三个竞争假设（A 目标几何不可达 / B 优化器局部极小 / C 近奇异）中锁定根因。
>
> 证据来源：8-14 抓包静态帧（仓库内 fixture `rokoko_hand_receiver/test/fixtures/captured_left_glove_v3.json`）+ 8-17 真机录制两段（`runs/session_left.jsonl`、`runs/session_left_v2.jsonl`，后者含 P0–P7 姿态标记）。判别工具见 `src/collection/omni_hand/hand_retargeting/scripts/`（录制/判别脚本），测试见 `test/test_ik_failure_diagnose.py`。
>
> 边界：本报告只验证 receiver + hand_retargeting 两节点的软件链路，不含任何真机硬件动作验证；结论覆盖"手套数据 → command"这一段的算法行为。

## 1. 裁决结论

**失败原因是假设 A：归一化生成的三维目标点在机械手可达集之外。** B（局部极小）与 C（近奇异）被逐帧证据排除。

- 判别样本：v2 录制 12,883 帧，每指抽样 12 帧，**60/60 全部裁决 A**；其中 9 帧同时存在 B 成分（多起点能把单起点残差从 1.1~1.9 降到 0.56~1.35），但降后仍远高于验收阈值 0.05，即"单起点陷入局部极小"是真实存在但**次要**的现象。
- 判定依据（对每个失败样本）：多点重试 r_ms 与 36 万点全局网格 r_grid 收敛到同一残差下限且 ≫ 0.05；10× 预算重跑残差不变（排除预算不足）；停止点投影梯度 ~1e-13 且关节顶在限位边界（真约束驻点）；指尖雅可比条件数 1.7~4.8（远非奇异，C 排除）。

A 的三种子类都有出现（53 方向偏离 / 4 目标太近 / 3 超伸）：

| 子类 | 含义 | 出现姿态 |
| --- | --- | --- |
| A-dir 方向偏离可达面 | 目标半径可达，但方向不在 1/2 自由度手指的可达弧/面上 | 所有姿态（包括直指静置 p0/p1） |
| A-under 目标太近 | 目标比手指能折返的最小半径还近 | 深弯曲：p3/p5/p6 的 index/middle/little |
| A-ext 超伸 | 目标超过该方向最大伸展 | p2 拇指、p3 食指、p6 无名指 |

## 2. 根因链条

目标生成公式（`session.py:145-153`）为 `t = root + ℓʳ · A_s · (Tip−Proximal)/ℓ_h_frozen`，即把人类指尖相对指根的弦向量按链长比直接映射。机械手的可达集远小于人手姿态空间，两处物理失配：

1. **折返半径**：机械手指尖能折回的最小半径/链长比实测为 thumb 0.54、index 0.42、middle 0.64、ring 0.42、little 0.42；而人手弯曲时 `‖u‖=|Tip−Proximal|/ℓ_h` 可低至 0.05~0.28（见 §4 表）。人手握拳/屈指越深，目标点越深入机械手"折不进去"的区域（A-under）。
2. **可达面维度**：index/ring/little 仅 2 个主动自由度（abad 单侧窄限位 ±0.17 rad 近似锁定），middle 仅 1 个；指尖可达集是 1D 弧/2D 窄带曲面。人手任意姿态的指尖方向（含外展、非平面弯曲分量）一般不落在这条窄带上（A-dir），**直指静置也挂**（p0 静置残差 0.22~0.51）就是这个原因。

上游体检（T4）排除替代解释：冻结长度 8.3~11.1cm 在解剖合理范围、`‖u‖` 直指时≈1、左手拇指 X 符号与左侧限位一致、原始帧全部有限、30Hz 无丢帧——**手套数据与归一化本身没有接线/缩放错误**，问题是"人手姿态空间 ≫ 机械手可达空间"的结构性失配在目标生成处没有做可达性投影。

## 3. 三个假设的逐帧排除证据

| 假设 | 判据 | 实测 | 裁决 |
| --- | --- | --- | --- |
| B 局部极小 | 多起点（33~66 个）能否越过阈值 | 9/60 帧多起点改善，但下限仍 ≫0.05；其余帧 r_ms=r_single | 排除为主因，B 是次要伴随现象 |
| C 近奇异 | σ_min(G)/σ_max(G) | 1.7~4.8（健康），G 满秩 | 排除 |
| A 几何不可达 | 全局网格下限 r_grid vs τ | 全部样本 r_grid ≥ 0.10 ≫ 0.05，且 r_grid≈r_ms | **确认** |
| 预算不足（非 A/B/C） | 10× 预算残差 | 不变 | 排除 |

## 5. 关键旁证

- **系统本身能出 command**：v1 录制中出现 587 帧 `tracking` 阶段（五指均有有效解），该窗口内 `command_published=true` 占 587/587——链路端到端可发布，问题只在"目标可达性"。
- **恢复死锁（独立次要问题）**：v2 会话全程 `recovery-confirming`。会话在录制间隙进入 stale 后，退出条件要求"连续 3 帧五根手指全部有效"，而可达性问题保证该条件永不满足 → 一旦 stale 永不恢复，必须重启节点。这是 stale 恢复设计与可达性失配叠加产生的次生问题，建议单独开 ticket。
- **重放保真度**：离线重放与线上录制残差逐帧对比（容差 0.02）——thumb 99.99%、little 98.8%、index 98.0%、middle 84.6%、ring 81.3%。middle/ring 的偏差来自线上节点 warm-start 历史（早晨会话遗留的有效解）与离线全新会话的初值差异，恰好再次印证 warm-start 会改变收敛结果（B 成分存在的旁证）；离线裁决使用自身一致的重放结果，不受影响。

## 6. 后续建议（不含实施）

修复方向按根因排序，具体方案需另开 spec/tickets：

1. **目标生成处引入可达性投影**（首选）：目标点先投影到各指可达流形（可用本报告同一套网格/多起点工具离线求解），或改目标定义为"方向 + 折返比"并裁剪到 [min_ratio, 1]×方向锥内；
2. **或放宽验收**：不可能修复几何失配本身，只能降低对深弯曲姿态的跟随质量要求（需产品决策）；
3. **stale 恢复死锁**（§5）：降低恢复门槛或加"长期无有效解自动复位"；
4. 若上游可调，优先让 Rokoko 输出避免深弯曲非物理姿态（`‖u‖<0.2` 的帧占失败帧主要成分，见 §4 p5 小指 0.05）。
