# Dexhit 项目总览

Dexhit 的第一版范围是一条可追踪的机器人数据到部署主链：采集现场数据，保留可回放的原始记录，处理为训练数据，训练策略模型，再把模型交给部署运行时。

## 主链

```text
collection → raw MCAP → processing → LeRobotDataset v3 → training → ACT bundle → deployment
```

主链中的产物含义：

- `raw MCAP` 是 collection 的原始记录边界，保留采集事实，不能被后续处理覆盖。
- `LeRobotDataset v3` 是 processing 对训练数据的规范化交付边界。
- `ACT bundle` 是 training 面向 deployment 的模型交付边界。

## 范围边界

当前只固定阶段名称、数据方向、文档和源码落点。具体传感器、消息 schema、硬件驱动、运行命令、依赖版本和部署平台，待对应阶段的工程任务确认后再进入权威文档。

项目事实写在 `01_知识/`，必须遵守的规则写在 `02_约束/`，一次性的推进状态写在 `03_工程/`。历史材料和学习材料分别隔离到 `98_archive/` 与 `99_learning/`。
