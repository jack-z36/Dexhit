# 人手归一化与 OmniHand O10 单指 IK 算法基线

本文沉淀 Rokoko Smartgloves 到 OmniHand O10 主动关节目标之间已经确认的数学算法与运行语义。本文是后续实现 spec 的算法基线；凡标为“未决”的内容都不得由实现者自行猜测或悄悄加入。

若历史聊天导出、早期算法草稿或参考项目实现与本文冲突，以本文为当前已确认算法口径；参考项目只提供证据和实现思路，不自动成为本项目契约。

本文只描述手部重定向算法，不重新定义 UDP/JSON 解析、O10 硬件通信或最终关节变化率安全限制。O10 控制命令顺序和限位同时受《OmniHand O10 控制契约与模块边界》约束。

## 1. 已确定的目标与范围

对每个逻辑手侧，算法把一帧 Rokoko 21 节点手部骨架转换为 OmniHand O10 的 10 维主动关节目标。处理过程为：

```text
Rokoko 21 节点手部帧
  -> 人体解剖学手掌坐标系
  -> 运行期人体手指尺度冻结
  -> 五个 O10 指尖目标
  -> 五个相互独立的低维 IK
  -> 10 维 O10 主动关节目标
```

已经确定的边界如下：

- 左右手独立处理，可同时运行；一侧失败不得阻断另一侧。
- 只控制 O10 的 10 个主动手指关节，不控制腕部或机械臂。
- 五根手指分别求解 IK；O10 机构不存在跨手指的主动—被动关节耦合。
- IK 只优化主动关节。6 个被动关节由固定版本 MJCF 中的耦合多项式严格派生，然后用完整 16 关节状态做 FK。
- Phase 1 的单指数值后端固定为 NLopt SLSQP；运行时解析梯度由 Pinocchio 完整指链平移雅可比和 MJCF 耦合雅可比按链式法则组成，中心数值差分只用于离线测试。
- 人体目标只使用节点位置。Rokoko `Hand.rotation` 和各节点四元数不参与本文算法。
- 当前 IK 目标只约束指尖位置，不约束指尖姿态。
- 本次运行的人体手指长度自动估计并冻结，不要求操作者执行规定校准手势。
- 一次进程运行期间只允许同一操作者和同一 Rokoko Actor Profile；冻结长度不会在运行中被静默改写。
- 第一版要求 Rokoko 输入频率由操作者配置为低于 IK 的可持续吞吐；过载调度策略暂不属于本文算法。

若一个向量写为 \({}^{A}\mathbf v\)，左上标 \(A\) 表示该向量的数值表达在哪个坐标系中，不表示幂。

若一个旋转矩阵写为 \({}^{A}\mathbf R_B\)，它把坐标系 \(B\) 中表达的向量转换到坐标系 \(A\)：

\[
{}^{A}\mathbf v
=
{}^{A}\mathbf R_B\,{}^{B}\mathbf v.
\]

矩阵 \({}^{A}\mathbf R_B\) 的三列依次是坐标系 \(B\) 的 \(+X,+Y,+Z\) 轴在坐标系 \(A\) 中的表达。

### 2.2 手侧、手指、节点与帧索引

逻辑手侧集合定义为：

\[
\mathcal S=\{L,R\},
\]

其中手侧下标 \(s=L\) 表示左手，\(s=R\) 表示右手。

手指集合定义为：

\[
\mathcal F=\{L,R,M,I,T\},
\]

其中手指下标的含义为：

| 手指下标 \(f\) | 含义 |
| --- | --- |
| \(T\) | thumb，拇指 |
| \(I\) | index，食指 |
| \(M\) | middle，中指 |
| \(R\) | ring，无名指 |
| \(L\) | little，小指 |

符号 \(L\) 和 \(R\) 会同时出现在手侧集合和手指集合中，其含义由下标位置唯一确定。例如：

- \(\mathbf X_{L,R,k}\)：左手无名指节点；
- \(\mathbf X_{R,L,k}\)：右手小指节点。

算法内部涉及数组和最终关节拼接时，五指固定顺序定义为有序元组：

\[
\overrightarrow{\mathcal F}=(T,I,M,R,L).
\]

每根手指的 Rokoko 节点索引集合定义为：

\[
\mathcal K=\{0,1,2,3\},
\]

且：

| 节点下标 \(k\) | Rokoko 语义 |
| ---: | --- |
| 0 | `Proximal` |
| 1 | `Medial` |
| 2 | `Distal` |
| 3 | `Tip` |

\(n\in\mathbb N_0\) 表示某一逻辑手侧收到的候选原始帧序号。左右手各自维护帧序列和算法状态，不要求两侧的 \(n\) 一致。

### 2.3 坐标系

| 坐标系 | 严格含义 |
| --- | --- |
| \(W\) | Rokoko 世界坐标系 |
| \(H_s[n]\) | 第 \(n\) 帧由人体节点位置构造的手侧 \(s\) 的解剖学手掌坐标系 |
| \(R_s\) | 手侧 \(s\) 的规范 O10 手掌坐标系；\(R_R\) 为模型 `R_palm` frame，\(R_L\) 为模型 `L_palm` frame |

\(H_s[n]\) 随人体手掌运动逐帧变化。\(R_s\) 固定在对应 O10 手掌模型上，不随人体帧变化。

### 2.4 Rokoko 输入符号

对 \(s\in\mathcal S,f\in\mathcal F,k\in\mathcal K,n\in\mathbb N_0\)，定义：

\[
{}^W\mathbf X_{s,f,k}[n]\in\mathbb R^3
\]

为相应 Rokoko 手指节点的位置，表达在 \(W\) 中。

定义：

\[
{}^W\mathbf O_s[n]\in\mathbb R^3
\]

为同侧 Rokoko `Hand.position`，也是人体解剖学手掌坐标系的原点。

原始帧还包含 `Hand.rotation` 和各节点 orientation 四元数。它们由接收层保留以便录制和诊断，但本文不为其引入计算符号，因为它们不进入任何目标生成、尺度估计、坐标变换或 IK 公式。

进入本文算法的一侧原始帧必须能按节点名称唯一取得一个 `Hand` 节点，以及五根手指各自的 `Proximal`、`Medial`、`Distal`、`Tip`，合计 21 个节点。本文公式不以数组位置猜测节点语义。所有 position 必须来自同一帧、使用同一个 Rokoko 世界坐标系和同一个长度单位；该单位的绝对名称即使尚未确认，也会在式（27）的人体比值中相消。凡涉及 \(W\) 中长度的阈值，必须使用与输入 position 一致的单位。

### 2.5 机器人模型与 IK 符号

定义：

\[
\mathbf q_{s,f}\in\mathbb R^{d_f}
\]

为手侧 \(s\)、手指 \(f\) 的主动关节向量，\(d_f\) 为该指主动关节数。

定义：

\[
\overline{\mathbf q}_{s,f}\in\mathbb R^{r_f}
\]

为同一手指的完整关节向量，包含主动关节及由机械耦合派生的被动关节，\(r_f\) 为完整关节数。上横线只表示“完整状态”，不表示均值。

各指维度和顺序为：

| \(f\) | \(d_f\) | 主动关节向量 \(\mathbf q_{s,f}\) | \(r_f\) | 完整关节向量 \(\overline{\mathbf q}_{s,f}\) |
| --- | ---: | --- | ---: | --- |
| \(T\) | 3 | `(thumb_roll, thumb_abad, thumb_mcp)` | 5 | `(thumb_roll, thumb_abad, thumb_mcp, thumb_pip, thumb_dip)` |
| \(I\) | 2 | `(index_abad, index_pip)` | 3 | `(index_abad, index_pip, index_dip)` |
| \(M\) | 1 | `(middle_pip)` | 2 | `(middle_pip, middle_dip)` |
| \(R\) | 2 | `(ring_abad, ring_pip)` | 3 | `(ring_abad, ring_pip, ring_dip)` |
| \(L\) | 2 | `(pinky_abad, pinky_pip)` | 3 | `(pinky_abad, pinky_pip, pinky_dip)` |

因此：

\[
\sum_{f\in\mathcal F}d_f=10,
\qquad
\sum_{f\in\mathcal F}r_f=16.
\]

第 \(j\) 个主动关节的下限和上限分别写为：

\[
\underline q_{s,f,j},\qquad \overline q_{s,f,j},
\]

其中此处 \(\overline q_{s,f,j}\) 是标量上限；带粗体的 \(\overline{\mathbf q}_{s,f}\) 才表示完整关节向量。

单指主动关节可行域定义为：

\[
\boxed{
\mathcal Q_{s,f}
=
\prod_{j=1}^{d_f}
[\underline q_{s,f,j},\overline q_{s,f,j}]
}
\tag{1}
\]

具体主动关节限位遵循《OmniHand O10 控制契约与模块边界》，并必须与运行时固定版本模型一致。

| \(\varepsilon_x>0\) | 输入长度单位 | 正交化人体掌横向轴最小有效长度 |
| \(\varepsilon_\ell>0\) | 输入长度单位 | 人体完整指链最小合法长度 |
| \(N\in\mathbb N\) | 样本数 | 单个长度稳定窗口的合法样本数 |
| \(K\in\mathbb N\) | 窗口数 | 冻结前连续稳定窗口数 |
| \(\tau_{\rho,f}>0\) | 无量纲 | 手指 \(f\) 的窗口相对离散度上限 |
| \(\varepsilon_{\mathrm{length},f}>0\) | 无量纲 | 冻结后当前长度相对偏差上限 |
| \(\varepsilon_{\mathrm{IK},f}>0\) | 无量纲 | 单指 IK 归一化残差上限 |
| \(N_{\mathrm{eval},\max}\in\mathbb N\) | 评估次数 | 单指单帧目标/导数最大评估次数 |
| \(T_{\max}>0\) | 时间 | 单指单帧最大求解耗时 |

## 3. 人体解剖学手掌坐标系

### 3.1 原点与纵向轴

人体掌坐标原点就是 Rokoko `Hand.position`：

\[
\boxed{
{}^W\mathbf o_{H_s}[n]
=
{}^W\mathbf O_s[n]
}
\tag{2}
\]

为避免与手指下标 \(R\) 发生语义混淆，四指 Proximal 中心明确写为：

\[
\boxed{
{}^W\mathbf C_s[n]
=
\frac{1}{4}
\left(
{}^W\mathbf X_{s,I,0}[n]
+{}^W\mathbf X_{s,M,0}[n]
+{}^W\mathbf X_{s,R,0}[n]
+{}^W\mathbf X_{s,L,0}[n]
\right)
}
\tag{3}
\]

未经归一化的纵向向量为：

\[
{}^W\mathbf y_{\mathrm{raw},s}[n]
=
{}^W\mathbf C_s[n]-{}^W\mathbf O_s[n].
\tag{4}
\]

定义配置参数 \(\varepsilon_y>0\) 为构造人体掌纵向轴所允许的最小有效长度。只有满足：

\[
\|{}^W\mathbf y_{\mathrm{raw},s}[n]\|_2>\varepsilon_y
\tag{5}
\]

才定义单位纵向轴：

\[
\boxed{
{}^W\widehat{\mathbf y}_{H_s}[n]
=
\frac{{}^W\mathbf y_{\mathrm{raw},s}[n]}
{\|{}^W\mathbf y_{\mathrm{raw},s}[n]\|_2}
}
\tag{6}
\]

其解剖学语义对左右手一致：

\[
+Y:\quad \text{掌根}\rightarrow\text{四指根部中心}.
\]

### 3.2 左右手横向轴

未经正交化的横向向量按手侧定义为：

\[
\boxed{
{}^W\mathbf x_{\mathrm{raw},s}[n]
=
\begin{cases}
{}^W\mathbf X_{R,I,0}[n]-{}^W\mathbf X_{R,L,0}[n], & s=R,\\[4pt]
{}^W\mathbf X_{L,L,0}[n]-{}^W\mathbf X_{L,I,0}[n], & s=L.
\end{cases}
}
\tag{7}
\]

因此：

- 右手 \(+X\)：小指侧指向拇指侧，即 `rightLittleProximal -> rightIndexProximal`；
- 左手 \(+X\)：拇指侧指向小指侧，即 `leftIndexProximal -> leftLittleProximal`。

使用 Gram–Schmidt 正交化去除横向量在 \(+Y\) 上的分量：

\[
\boxed{
{}^W\widetilde{\mathbf x}_s[n]
=
{}^W\mathbf x_{\mathrm{raw},s}[n]
-
\left(
({}^W\mathbf x_{\mathrm{raw},s}[n])^\mathsf T
{}^W\widehat{\mathbf y}_{H_s}[n]
\right)
{}^W\widehat{\mathbf y}_{H_s}[n]
}
\tag{8}
\]

定义配置参数 \(\varepsilon_x>0\) 为正交化后横向轴所允许的最小有效长度。只有满足：

\[
\|{}^W\widetilde{\mathbf x}_s[n]\|_2>\varepsilon_x
\tag{9}
\]

才定义：

\[
\boxed{
{}^W\widehat{\mathbf x}_{H_s}[n]
=
\frac{{}^W\widetilde{\mathbf x}_s[n]}
{\|{}^W\widetilde{\mathbf x}_s[n]\|_2}
}
\tag{10}
\]

### 3.3 掌面法向轴与旋转矩阵

左右手统一定义：

\[
\boxed{
{}^W\widehat{\mathbf z}_{H_s}[n]
=
{}^W\widehat{\mathbf x}_{H_s}[n]
\times
{}^W\widehat{\mathbf y}_{H_s}[n]
}
\tag{11}
\]

左右手横向轴采用相反的解剖方向，目的就是让两侧均满足右手系：

\[
+Z:\quad \text{掌面向外},
\qquad
+X\times +Y=+Z.
\]

人体解剖学手掌坐标系到世界坐标系的旋转矩阵为：

\[
\boxed{
{}^W\mathbf R_{H_s}[n]
=
\begin{bmatrix}
{}^W\widehat{\mathbf x}_{H_s}[n] &
{}^W\widehat{\mathbf y}_{H_s}[n] &
{}^W\widehat{\mathbf z}_{H_s}[n]
\end{bmatrix}
\in SO(3)
}
\tag{12}
\]

### 3.4 世界坐标转换到人体掌坐标

对每一个 \(f\in\mathcal F,k\in\mathcal K\)：

\[
\boxed{
{}^{H_s}\mathbf X_{s,f,k}[n]
=
({}^W\mathbf R_{H_s}[n])^\mathsf T
\left(
{}^W\mathbf X_{s,f,k}[n]-{}^W\mathbf O_s[n]
\right)
}
\tag{13}
\]

式（13）同时消除人体手掌在 Rokoko 世界坐标中的平移和整体旋转。

### 3.5 掌坐标系构造失败

若存在以下任一情况，则手侧 \(s\) 的第 \(n\) 帧为“整侧几何无效帧”：

- `Hand.position` 或用于式（3）、式（7）的四个 Proximal 位置存在非有限值；
- 式（5）不成立；
- 式（9）不成立；
- 构造出的坐标轴或旋转矩阵含非有限值。

整侧几何无效帧不得用于更新长度估计、不得运行任何手指 IK，也不得产生该侧新命令。若该侧此前已经输出过命令，下游继续保持上一目标；算法发布诊断状态而不伪造当前目标。

`Hand.rotation` 不作为坐标系构造失败的判据，因为它不参与本文坐标系构造。

## 4. 启动期人体手指长度估计与冻结

### 4.1 当前人体指链长度

对每一根手指，定义相邻节点的三段长度：

\[
\ell^h_{s,f,k}[n]
=
\left\|
{}^{H_s}\mathbf X_{s,f,k+1}[n]
-{}^{H_s}\mathbf X_{s,f,k}[n]
\right\|_2,
\qquad k\in\{0,1,2\}.
\tag{14}
\]

定义人体完整指链长度：

\[
\boxed{
\ell^h_{s,f}[n]
=
\sum_{k=0}^{2}\ell^h_{s,f,k}[n]
}
\tag{15}
\]

上标 \(h\) 表示 human。\(\ell^h_{s,f}[n]\) 的单位与 Rokoko position 单位相同。

定义 \(\varepsilon_\ell>0\) 为可接受人体指链总长度的最小值。手指 \((s,f)\) 在第 \(n\) 帧产生一个“合法长度样本”当且仅当：

- 当前帧不是整侧几何无效帧；
- 该指四个节点位置均为有限值；
- \(\ell^h_{s,f}[n]>\varepsilon_\ell\)。

### 4.2 只含合法样本的窗口

对每一个 \((s,f)\)，令：

\[
i_{s,f}[u]\in\mathbb N_0
\]

表示该指第 \(u\) 个合法长度样本来自哪个原始帧，\(u\in\mathbb N_0\)。因此：

\[
i_{s,f}[0]<i_{s,f}[1]<i_{s,f}[2]<\cdots.
\]

定义配置参数：

| 参数 | 含义 |
| --- | --- |
| \(N\in\mathbb N, N\ge 1\) | 一个完整滑动窗口包含的合法长度样本数 |
| \(K\in\mathbb N, K\ge 1\) | 冻结前必须连续满足稳定条件的完整窗口数 |
| \(\tau_{\rho,f}>0\) | 手指 \(f\) 允许的窗口内相对长度离散度 |

当 \(u\ge N-1\) 时，定义第 \(u\) 个完整窗口对应的原始帧索引集合：

\[
\boxed{
\mathcal I_{s,f}[u]
=
\{i_{s,f}[u-N+1],\ldots,i_{s,f}[u]\}
}
\tag{16}
\]

无效帧不进入窗口，也不产生新的窗口端点；“连续窗口”是指合法样本序列上相邻的窗口端点。

### 4.3 中位数与归一化中位绝对偏差

窗口长度中位数定义为：

\[
\boxed{
m_{s,f}[u]
=
\operatorname{median}
\left\{
\ell^h_{s,f}[i]\mid i\in\mathcal I_{s,f}[u]
\right\}
}
\tag{17}
\]

归一化中位绝对偏差定义为：

\[
\boxed{
\rho_{s,f}[u]
=
\frac{
\operatorname{median}
\left\{
\left|\ell^h_{s,f}[i]-m_{s,f}[u]\right|
\mid i\in\mathcal I_{s,f}[u]
\right\}
}{m_{s,f}[u]}
}
\tag{18}
\]

\(m_{s,f}[u]\) 的单位是长度，\(\rho_{s,f}[u]\) 无量纲。只有 \(m_{s,f}[u]>\varepsilon_\ell\) 时才允许计算式（18）。

第 \(u\) 个完整窗口稳定当且仅当：

\[
\operatorname{StableWindow}_{s,f}[u]
\iff
m_{s,f}[u]>\varepsilon_\ell
\land
\rho_{s,f}[u]\le\tau_{\rho,f}.
\tag{19}
\]

### 4.4 冻结规则

令 \(u^{\mathrm{freeze}}_{s,f}\) 为首次满足以下条件的合法样本序号：

\[
\boxed{
\bigwedge_{v=u-K+1}^{u}
\operatorname{StableWindow}_{s,f}[v]
}
\tag{20}
\]

其中所有 \(v\) 都必须已经形成完整窗口。达到式（20）后，冻结该指本次运行的人体指链长度：

\[
\boxed{
\overline{\ell}^{\,h}_{s,f}
=
m_{s,f}[u^{\mathrm{freeze}}_{s,f}]
}
\tag{21}
\]

上方横线表示“冻结值”，不是算术平均数。

冻结后必须满足以下不变量：

\[
\forall n>i_{s,f}[u^{\mathrm{freeze}}_{s,f}],\qquad
\overline{\ell}^{\,h}_{s,f}\ \text{保持不变}.
\tag{22}
\]

程序每次启动都从未冻结状态开始重新估计。第一版不提供运行中重新估计，不检测换人，也不保存跨进程的操作者手型档案。

### 4.5 同侧开始求解的尺度条件

定义：

\[
\operatorname{lengthFrozen}_{s,f}[n]
\]

表示截至第 \(n\) 帧，\((s,f)\) 已经按式（21）冻结。

只有同侧五根手指全部冻结后，才允许该侧生成 O10 指尖目标并开始 IK：

\[
\boxed{
\operatorname{allLengthsFrozen}_s[n]
\iff
\bigwedge_{f\in\mathcal F}
\operatorname{lengthFrozen}_{s,f}[n]
}
\tag{23}
\]

在式（23）成立之前，不允许使用临时中位数代替冻结长度产生部分手指控制。

### 4.6 冻结后的当前长度异常

长度冻结后，仍然为当前帧计算式（15）。定义当前长度相对冻结值的偏差：

\[
\boxed{
\gamma_{s,f}[n]
=
\frac{
|\ell^h_{s,f}[n]-\overline{\ell}^{\,h}_{s,f}|
}{
\overline{\ell}^{\,h}_{s,f}
}
}
\tag{24}
\]

定义配置参数 \(\varepsilon_{\mathrm{length},f}>0\) 为手指 \(f\) 允许的冻结后相对长度偏差。若：

\[
\gamma_{s,f}[n]>\varepsilon_{\mathrm{length},f},
\tag{25}
\]

则当前帧的该指输入无效：不更新该指 IK，且绝不修改 \(\overline{\ell}^{\,h}_{s,f}\)。若该指已有历史有效 IK 目标，则保持该指历史目标；同侧其他输入合法的手指仍可更新。

若异常节点是食指、中指、无名指或小指的 Proximal，导致第 3 节掌坐标系不能构造，则适用“整侧几何无效帧”，而不是普通单指保持语义。

## 5. 无量纲人体指尖几何

在同侧五指长度均冻结且当前帧掌坐标有效时，对每根当前输入合法的手指定义从 Proximal 到 Tip 的向量：

\[
\boxed{
{}^{H_s}\mathbf v_{s,f}[n]
=
{}^{H_s}\mathbf X_{s,f,3}[n]
-{}^{H_s}\mathbf X_{s,f,0}[n]
}
\tag{26}
\]

\({}^{H_s}\mathbf v_{s,f}[n]\) 的单位是长度。定义无量纲人体指尖几何向量：

\[
\boxed{
{}^{H_s}\mathbf u_{s,f}[n]
=
\frac{{}^{H_s}\mathbf v_{s,f}[n]}
{\overline{\ell}^{\,h}_{s,f}}
}
\tag{27}
\]

\({}^{H_s}\mathbf u_{s,f}[n]\) 不是单位方向向量。其方向表示指根到指尖的方向，其模长表示当前 root-to-tip 距离相对于本次运行冻结完整指链长度的比例；手指弯曲时该模长通常变小。算法不得再次把 \(\mathbf u\) 归一化成单位长度，否则会丢失弯曲信息。

这里的人体尺度归一化只负责消除不同操作者手指绝对长度的影响；它尚未评价 O10 IK 解的好坏。

## 6. 固定 O10 几何与手掌方向映射

### 6.1 模型来源一致性

对每个手侧，以下三类机器人几何量必须在启动时从同一个固定版本的对应侧 URDF，经 Pinocchio 在零关节状态下计算：

- O10 指根 \({}^{R_s}\mathbf a_{s,f}\)；
- O10 指链长度 \(\ell^r_{s,f}\)；
- 手掌方向映射矩阵 \(\mathbf A_s\)。

运行时不得另行维护一份手写几何常量。MJCF 在本文中只作为主动—被动耦合多项式的数据来源，不作为第二套几何来源。

### 6.2 指根和完整机器人指链长度

令：

\[
{}^{R_s}\mathbf P^r_{s,f,h}(\mathbf 0)
\]

表示手指 \(f\) 的第 \(h\) 个运动关节原点在零关节状态下的位置，表达在 \(R_s\) 中，其中 \(h\in\{0,\ldots,r_f-1\}\)。令：

\[
{}^{R_s}\mathbf P^r_{s,f,\mathrm{tip}}(\mathbf 0)
\]

表示相应 tip frame 原点在零关节状态下的位置。

O10 指根定义为该指第一个运动关节的原点：

\[
\boxed{
{}^{R_s}\mathbf a_{s,f}
=
{}^{R_s}\mathbf P^r_{s,f,0}(\mathbf 0)
}
\tag{28}
\]

五个首关节分别为：`thumb_roll`、`index_abad`、`middle_pip`、`ring_abad`、`pinky_abad`。

O10 完整指链长度定义为零状态下相邻运动关节原点之间的路径长度，再加最后一个运动关节原点到 tip frame 原点的长度：

\[
\boxed{
\ell^r_{s,f}
=
\sum_{h=0}^{r_f-2}
\left\|
{}^{R_s}\mathbf P^r_{s,f,h+1}(\mathbf 0)
-{}^{R_s}\mathbf P^r_{s,f,h}(\mathbf 0)
\right\|_2
+
\left\|
{}^{R_s}\mathbf P^r_{s,f,\mathrm{tip}}(\mathbf 0)
-{}^{R_s}\mathbf P^r_{s,f,r_f-1}(\mathbf 0)
\right\|_2
}
\tag{29}
\]

必须满足 \(\ell^r_{s,f}>0\)。该量不是从指根直连 tip 的弦长。

### 6.3 O10 手掌的解剖学基

机器人掌根参考点已经固定为规范 O10 手掌坐标系原点：

\[
\boxed{
{}^{R_s}\mathbf O_s^r=\mathbf 0_3
}
\tag{30}
\]

定义 O10 四指根部中心：

\[
{}^{R_s}\mathbf C_s^r
=
\frac{1}{4}
\left(
{}^{R_s}\mathbf a_{s,I}
+{}^{R_s}\mathbf a_{s,M}
+{}^{R_s}\mathbf a_{s,R}
+{}^{R_s}\mathbf a_{s,L}
\right).
\tag{31}
\]

机器人掌纵向单位轴为：

\[
\boxed{
{}^{R_s}\widehat{\mathbf y}_s^r
=
\frac{{}^{R_s}\mathbf C_s^r-{}^{R_s}\mathbf O_s^r}
{\|{}^{R_s}\mathbf C_s^r-{}^{R_s}\mathbf O_s^r\|_2}
}
\tag{32}
\]

机器人掌未经正交化的横向量为：

\[
{}^{R_s}\mathbf x^r_{\mathrm{raw},s}
=
\begin{cases}
{}^{R_R}\mathbf a_{R,I}-{}^{R_R}\mathbf a_{R,L}, & s=R,\\[4pt]
{}^{R_L}\mathbf a_{L,L}-{}^{R_L}\mathbf a_{L,I}, & s=L.
\end{cases}
\tag{33}
\]

正交化及归一化后：

\[
{}^{R_s}\widetilde{\mathbf x}_s^r
=
{}^{R_s}\mathbf x^r_{\mathrm{raw},s}
-
\left(
({}^{R_s}\mathbf x^r_{\mathrm{raw},s})^\mathsf T
{}^{R_s}\widehat{\mathbf y}_s^r
\right)
{}^{R_s}\widehat{\mathbf y}_s^r,
\tag{34}
\]

\[
\boxed{
{}^{R_s}\widehat{\mathbf x}_s^r
=
\frac{{}^{R_s}\widetilde{\mathbf x}_s^r}
{\|{}^{R_s}\widetilde{\mathbf x}_s^r\|_2}
}
\tag{35}
\]

\[
\boxed{
{}^{R_s}\widehat{\mathbf z}_s^r
=
{}^{R_s}\widehat{\mathbf x}_s^r
\times
{}^{R_s}\widehat{\mathbf y}_s^r
}
\tag{36}
\]

固定手掌方向映射矩阵定义为：

\[
\boxed{
\mathbf A_s
=
\begin{bmatrix}
{}^{R_s}\widehat{\mathbf x}_s^r &
{}^{R_s}\widehat{\mathbf y}_s^r &
{}^{R_s}\widehat{\mathbf z}_s^r
\end{bmatrix}
\in SO(3)
}
\tag{37}
\]

模型加载时必须验证式（32）和式（35）的分母非零、所有量有限且 \(\mathbf A_s^\mathsf T\mathbf A_s=\mathbf I_3\)、\(\det(\mathbf A_s)=+1\)；验证失败时该侧模型不得进入运行状态。

\(\mathbf A_s\) 一侧五指共享，只依赖逻辑手侧和固定 O10 模型，不依赖操作者、帧、手指或 FK 后端。它把人体解剖学掌坐标中的数值分量映射到规范 O10 掌坐标：

\[
{}^{R_s}\mathbf u_{s,f}^{r}[n]
=
\mathbf A_s\,{}^{H_s}\mathbf u_{s,f}[n].
\tag{38}
\]

## 7. O10 指尖目标生成

对当前输入合法的手指，O10 指尖目标定义为：

\[
\boxed{
{}^{R_s}\mathbf y_{s,f}[n]
=
{}^{R_s}\mathbf a_{s,f}
+
\ell^r_{s,f}
\mathbf A_s
{}^{H_s}\mathbf u_{s,f}[n]
}
\tag{39}
\]

代入式（27）可得等价形式：

\[
\boxed{
{}^{R_s}\mathbf y_{s,f}[n]
=
{}^{R_s}\mathbf a_{s,f}
+
\frac{\ell^r_{s,f}}{\overline{\ell}^{\,h}_{s,f}}
\mathbf A_s
{}^{H_s}\mathbf v_{s,f}[n]
}
\tag{40}
\]

式（39）包含三个不可混淆的部分：

1. \({}^{R_s}\mathbf a_{s,f}\)：把目标锚定到对应 O10 指根；
2. \(\mathbf A_s\)：只转换解剖学方向分量；
3. \(\ell^r_{s,f}/\overline{\ell}^{\,h}_{s,f}\)：把人体尺度换成对应机器人手指尺度。

尺寸归一化只能让目标尺度合理，不能保证式（39）的目标位于受 O10 关节限位约束的可达空间。可达性由 IK 求解后的残差判定。

## 8. 主动关节到完整关节的严格耦合

### 8.1 耦合函数定义

定义单指耦合映射：

\[
\boxed{
\mathbf G_{s,f}:\mathcal Q_{s,f}\rightarrow\mathbb R^{r_f},
\qquad
\overline{\mathbf q}_{s,f}=\mathbf G_{s,f}(\mathbf q_{s,f})
}
\tag{41}
\]

定义四次多项式：

\[
\boxed{
P(x;c_0,c_1,c_2,c_3,c_4)
=
c_0+c_1x+c_2x^2+c_3x^3+c_4x^4
}
\tag{42}
\]

本文采用固定 O10 MJCF 零参考状态下 `equality/joint` 的 `polycoef`。被动关节必须由主动关节显式计算；不得假定 Pinocchio 会执行 URDF `mimic`，也不得把被动关节作为独立优化变量。

式（43）至式（46）的当前证据基线为 ManusOmniBridge commit `f4fd0d913c2151bcb4be0d29fbc02761b9638009` 中的左右 O10 MJCF。该 commit 是文档证据版本，不等于最终运行时资产交付方案；后者仍属于第 14 节的未决边界。

\mathbf q_{s,T}
=
(q_{s,T,\mathrm{roll}},q_{s,T,\mathrm{abad}},q_{s,T,\mathrm{mcp}})^\mathsf T.
\]

左右手拇指均满足：

q_{s,T,\mathrm{pip}}=1.33q_{s,T,\mathrm{mcp}}.
\tag{43}
\]

\[
q_{R,T,\mathrm{dip}}
=
1.846q_{R,T,\mathrm{mcp}}
-0.853q_{R,T,\mathrm{mcp}}^2
+0.280q_{R,T,\mathrm{mcp}}^3.

q_{L,T,\mathrm{dip}}

\mathbf G_{s,T}(\mathbf q_{s,T})
=

\tag{45}
\]

### 8.3 食指、中指、无名指和小指耦合

对于 \(f\in\{I,M,R,L\}\)，令 \(q_{s,f,\mathrm{pip}}\) 表示该指主动屈伸关节，则：

\[
\boxed{
q_{s,f,\mathrm{dip}}
=
2.192q_{s,f,\mathrm{pip}}
-1.425q_{s,f,\mathrm{pip}}^2
+0.747q_{s,f,\mathrm{pip}}^3
-0.167q_{s,f,\mathrm{pip}}^4
}
\tag{46}
\]

食指、无名指和小指保留各自的主动 `abad`，中指没有主动 `abad`。据此按第 2.5 节规定的顺序构造 \(\mathbf G_{s,f}\)。

\boxed{
\mathbf G_s
=
\mathbf G_{s,T}\oplus
\mathbf G_{s,I}\oplus
\mathbf G_{s,M}\oplus
\mathbf G_{s,R}\oplus
\mathbf G_{s,L}
}
\tag{47}
\]

其中 \(\oplus\) 表示把互不共享输入变量的映射组成块对角式独立映射，不表示普通加法。

## 9. 完整 FK 与单指 IK 损失

### 9.1 完整 FK

定义单指 FK：

\[
\boldsymbol\Phi_{s,f}:\mathbb R^{r_f}\rightarrow\mathbb R^3,
\]

其输出为相应 O10 tip frame 原点在规范掌坐标 \(R_s\) 中的位置。主动关节候选对应的实际指尖位置为：

\[
\boxed{
{}^{R_s}\mathbf p_{s,f}(\mathbf q_{s,f})
=
\boldsymbol\Phi_{s,f}
\left(\mathbf G_{s,f}(\mathbf q_{s,f})\right)
}
\tag{48}
\]

FK 必须使用式（41）生成的完整状态，不能使用一个违反耦合关系的 16 维候选状态。

### 9.2 米制指尖误差

第 \(n\) 帧、候选 \(\mathbf q_{s,f}\) 的指尖误差向量定义为：

\[
\boxed{
\mathbf e_{s,f}[n](\mathbf q_{s,f})
=
{}^{R_s}\mathbf p_{s,f}(\mathbf q_{s,f})
-{}^{R_s}\mathbf y_{s,f}[n]
}
\tag{49}
\]

\(\mathbf e_{s,f}\in\mathbb R^3\)，单位是长度。其符号方向不影响平方损失，但该定义固定为“实际位置减目标位置”。

### 9.3 无量纲误差、残差与损失

定义无量纲误差向量：

\[
\boxed{
\mathbf r_{s,f}[n](\mathbf q_{s,f})
=
\frac{\mathbf e_{s,f}[n](\mathbf q_{s,f})}{\ell^r_{s,f}}
}
\tag{50}
\]

定义归一化指尖残差：

\[
\boxed{
\eta_{s,f}[n](\mathbf q_{s,f})
=
\|\mathbf r_{s,f}[n](\mathbf q_{s,f})\|_2
=
\frac{
\|{}^{R_s}\mathbf p_{s,f}(\mathbf q_{s,f})-{}^{R_s}\mathbf y_{s,f}[n]\|_2
}{\ell^r_{s,f}}
}
\tag{51}
\]

\(\eta_{s,f}\ge0\) 且无单位。它表示 O10 指尖位置误差占该机器人完整指链长度的比例。

基础单指 IK 损失固定为归一化残差的平方：

\[
\boxed{
J_{s,f}[n](\mathbf q_{s,f})
=
\eta_{s,f}^2[n](\mathbf q_{s,f})
=
\frac{
\|{}^{R_s}\mathbf p_{s,f}(\mathbf q_{s,f})-{}^{R_s}\mathbf y_{s,f}[n]\|_2^2
}{(\ell^r_{s,f})^2}
}
\tag{52}
\]

分母必须是 \((\ell^r_{s,f})^2\)，因为先用机器人指链长度归一化位置误差，再对其求平方。

这里必须区分两次尺度处理：

- 式（27）使用冻结人体长度 \(\overline{\ell}^{\,h}_{s,f}\)，用于生成与操作者绝对手型无关的 O10 目标；
- 式（51）、式（52）使用机器人长度 \(\ell^r_{s,f}\)，用于公平评价不同 O10 手指的 IK 解质量。

基础损失中不包含指尖方向、关节变化、上一帧关节角、碰撞、平滑或多指联合项。

### 9.4 单指约束优化问题

对每个当前输入合法的手指独立求解：

\[
\boxed{
\mathcal Q^{\mathrm{opt}}_{s,f}[n]
=
\underset{\mathbf q_{s,f}\in\mathcal Q_{s,f}}
{\operatorname{argmin}}
\;J_{s,f}[n](\mathbf q_{s,f})
}
\tag{53}
\]

其中 \(\mathcal Q^{\mathrm{opt}}_{s,f}[n]\) 是数学上所有全局最优主动关节向量组成的集合。\(\operatorname{argmin}\) 返回集合，是因为该问题可能存在多个同样好的最优解。

数值求解器实际返回的是搜索过程中找到的当前最佳候选 \(\widetilde{\mathbf q}_{s,f}[n]\)，不承诺它属于 \(\mathcal Q^{\mathrm{opt}}_{s,f}[n]\)。只有该候选通过第 10.2 节的有效性判定后，才记为 \(\mathbf q^\star_{s,f}[n]\)。三者不得混用：

| 符号 | 含义 |
| --- | --- |
| \(\mathcal Q^{\mathrm{opt}}_{s,f}[n]\) | 理论全局最优解集合 |
| \(\widetilde{\mathbf q}_{s,f}[n]\) | 数值求解器停止时的当前最佳候选 |
| \(\mathbf q^\star_{s,f}[n]\) | 已通过控制有效性判定的当前候选 |

### 9.5 耦合映射的解析雅可比

定义式（41）的耦合雅可比：

\[
\boxed{
\mathbf B_{s,f}(\mathbf q_{s,f})
=
\frac{\partial\mathbf G_{s,f}(\mathbf q_{s,f})}
{\partial\mathbf q_{s,f}}
\in\mathbb R^{r_f\times d_f}
}
\tag{53a}
\]

其中每个主动关节在完整状态中对应的导数为 1；由该主动关节驱动的被动关节使用耦合多项式的导数。对式（42）：

\[
\boxed{
\frac{\mathrm dP}{\mathrm dx}
=c_1+2c_2x+3c_3x^2+4c_4x^3
}
\tag{53b}
\]

因此，式（43）、式（44R）、式（44L）和式（46）的被动关节导数必须分别从其原多项式解析生成，不得维护一套与耦合值计算相互独立的手写导数常量。实现应让多项式求值和导数求值共享同一份已加载系数，以防二者漂移。

例如食指主动状态和完整状态若按下式排列：

\[
\mathbf q_{s,I}
=
(q_{s,I,\mathrm{abad}},q_{s,I,\mathrm{pip}})^\mathsf T,
\qquad
\overline{\mathbf q}_{s,I}
=
(q_{s,I,\mathrm{abad}},q_{s,I,\mathrm{pip}},P(q_{s,I,\mathrm{pip}}))^\mathsf T,
\]

则：

\[
\boxed{
\mathbf B_{s,I}
=
\begin{bmatrix}
1&0\\
0&1\\
0&P'(q_{s,I,\mathrm{pip}})
\end{bmatrix}
}
\tag{53c}
\]

### 9.6 指尖有效雅可比与损失梯度

Pinocchio 对完整单指状态计算 tip frame 的平移雅可比。定义：

\[
\boxed{
\mathbf J^{\mathrm{full}}_{s,f}
(\overline{\mathbf q}_{s,f})
=
\frac{
\partial\boldsymbol\Phi_{s,f}(\overline{\mathbf q}_{s,f})
}{
\partial\overline{\mathbf q}_{s,f}
}
\in\mathbb R^{3\times r_f}
}
\tag{53d}
\]

该雅可比的三维平移分量和式（49）的误差向量必须表达在同一规范掌坐标 \(R_s\) 中。实现使用 Pinocchio tip frame Jacobian 的 `LOCAL_WORLD_ALIGNED` 表达，并要求固定模型根坐标与 \(R_s\) 重合；不得把局部 tip 坐标分量直接与 \(R_s\) 中的误差相乘。

根据链式法则，指尖位置对主动关节的有效雅可比为：

\[
\boxed{
\mathbf J^{\mathrm{active}}_{s,f}(\mathbf q_{s,f})
=
\mathbf J^{\mathrm{full}}_{s,f}
(\mathbf G_{s,f}(\mathbf q_{s,f}))
\mathbf B_{s,f}(\mathbf q_{s,f})
\in\mathbb R^{3\times d_f}
}
\tag{53e}
\]

不得以“从完整雅可比中只抽取主动关节列”代替式（53e），因为那会遗漏主动关节经被动耦合关节影响指尖的路径。

式（52）对主动关节的解析梯度固定为：

\[
\boxed{
\nabla_{\mathbf q}J_{s,f}[n](\mathbf q_{s,f})
=
\frac{2}{(\ell^r_{s,f})^2}
\left(\mathbf J^{\mathrm{active}}_{s,f}(\mathbf q_{s,f})\right)^\mathsf T
\mathbf e_{s,f}[n](\mathbf q_{s,f})
}
\tag{53f}
\]

等价地：

\[
\nabla_{\mathbf q}J_{s,f}
=
\frac{2}{(\ell^r_{s,f})^2}
\mathbf B_{s,f}^\mathsf T
(\mathbf J^{\mathrm{full}}_{s,f})^\mathsf T
\mathbf e_{s,f}.
\tag{53g}
\]

### 9.7 Phase 1 优化后端

Phase 1 固定使用 NLopt `NLOPT_LD_SLSQP`，并采用以下契约：

- 一个优化器实例只求解一根手指的一帧主动关节候选；左右手和各手指的历史状态相互隔离；
- 优化变量只有 \(\mathbf q_{s,f}\)，被动关节已通过 \(\mathbf G_{s,f}\) 消元，不作为优化变量或额外等式约束；
- 上下界严格使用 \(\underline{\mathbf q}_{s,f}\) 与 \(\overline{\mathbf q}_{s,f}\)；
- 目标回调同时返回式（52）的损失值与式（53f）的解析梯度；
- 初值继续遵守式（55）：首次为关节范围中点，后续 warm start 为上一有效目标；
- 这是局部优化，不宣称返回理论全局最优解；
- Phase 1 不采用全局搜索、多初值搜索或运行时数值差分梯度。

SLSQP 负责依据目标梯度、边界和内部曲率近似选择搜索方向与步长；项目代码负责提供正确的损失、解析梯度、上下界、初值和停止条件。具体收敛阈值、最大评估次数和最大耗时仍由后续离线实验及性能基准确定。

### 9.8 解析梯度的离线验证

运行时不使用数值差分，但测试必须用中心差分独立验证式（53f）。令 \(\mathbf e_i\in\mathbb R^{d_f}\) 为第 \(i\) 个分量为 1、其余分量为 0 的单位向量，令 \(h_i>0\) 为测试扰动，则数值参考值为：

\[
\boxed{
\widehat g_i
=
\frac{
J_{s,f}(\mathbf q_{s,f}+h_i\mathbf e_i)
-J_{s,f}(\mathbf q_{s,f}-h_i\mathbf e_i)
}{2h_i}
}
\tag{53h}
\]

测试必须覆盖左右手、五根手指、多组可行域内部关节状态以及接近关节边界但扰动后仍合法的状态，并特别覆盖左右拇指不同的 DIP 多项式。差分步长和数值相等容差属于测试参数，必须通过量纲与数值实验确定。

## 10. IK 初始化、终止与候选提交

### 10.1 初始猜测

定义主动关节范围中点：

\[
\boxed{
\mathbf q^{\mathrm{mid}}_{s,f}
=
\frac{1}{2}
\left(
\underline{\mathbf q}_{s,f}
+\overline{\mathbf q}_{s,f}
\right)
}
\tag{54}
\]

其中 \(\underline{\mathbf q}_{s,f}\) 和 \(\overline{\mathbf q}_{s,f}\) 分别由各主动关节下限和上限按该指顺序组成。

定义 \(\operatorname{hasValidIK}_{s,f}[n]\) 表示截至第 \(n\) 帧，该指是否至少产生过一次有效 IK 解。第 \(n\) 帧的求解初值为：

\[
\boxed{
\mathbf q^{(0)}_{s,f}[n]
=
\begin{cases}
\mathbf q^{\mathrm{last}}_{s,f}[n-1], & \operatorname{hasValidIK}_{s,f}[n-1]=\mathrm{true},\\[4pt]
\mathbf q^{\mathrm{mid}}_{s,f}, & \operatorname{hasValidIK}_{s,f}[n-1]=\mathrm{false},
\end{cases}
}
\tag{55}
\]

其中 \(\mathbf q^{\mathrm{last}}_{s,f}[n-1]\) 是截至上一帧该指最近一次有效 IK 目标。式（55）中的中点只是搜索起点，不能作为未经验证的控制命令发送。

### 10.2 终止原因与候选有效性分离

定义：

- \(N_{\mathrm{eval},\max}\in\mathbb N\)：单指单帧允许的最大目标/导数评估次数；
- \(T_{\max}>0\)：单指单帧允许的最大求解耗时；
- \(\varepsilon_{\mathrm{IK},f}>0\)：手指 \(f\) 允许的最大归一化指尖残差。

优化器停止可能因为内部收敛、达到 \(N_{\mathrm{eval},\max}\)、达到 \(T_{\max}\) 或求解器异常。停止原因和候选有效性必须分开判断：

- 达到评估次数或时间上限，不自动表示失败；
- 优化器报告正常收敛，不自动表示候选可用于控制；
- 求解器抛出异常、候选包含 NaN/Infinity、主动关节越界、派生完整关节非有限或违反其模型范围时，直接拒绝候选；
- 其余候选统一通过归一化残差判定。

定义优化器停止后的当前最佳候选为 \(\widetilde{\mathbf q}_{s,f}[n]\)。定义：

\[
\widetilde\eta_{s,f}[n]
=
\eta_{s,f}[n](\widetilde{\mathbf q}_{s,f}[n]).
\tag{56}
\]

候选有效性为：

\[
\boxed{
\operatorname{IKValid}_{s,f}[n]
\iff
\operatorname{SolverUsable}_{s,f}[n]
\land
\operatorname{finite}(\widetilde{\mathbf q}_{s,f}[n])
\land
\widetilde{\mathbf q}_{s,f}[n]\in\mathcal Q_{s,f}
\land
\operatorname{FullStateValid}(\mathbf G_{s,f}(\widetilde{\mathbf q}_{s,f}[n]))
\land
\widetilde\eta_{s,f}[n]\le\varepsilon_{\mathrm{IK},f}
}
\tag{57}
\]

其中：

- \(\operatorname{SolverUsable}\) 表示求解器没有发生使候选不可信的异常；达到正常上限仍可以为 true；
- \(\operatorname{FullStateValid}\) 表示派生的完整关节状态全部有限并处于对应模型范围内；
- \(\varepsilon_{\mathrm{IK},f}\) 可以按手指配置，拇指允许与其余四指不同；数值必须通过离线模型实验及未来真实数据确定。

当式（57）成立时：

\[
\boxed{
\mathbf q^\star_{s,f}[n]
=
\widetilde{\mathbf q}_{s,f}[n]
}
\tag{58}
\]

并将其提交为该指新的 \(\mathbf q^{\mathrm{last}}_{s,f}[n]\)。未通过式（57）的当前最佳候选绝不覆盖历史有效目标。

## 11. 单指保持、手侧就绪与 10 维输出

### 11.1 单指提交状态

对每根手指维护最近有效目标：

\[
\mathbf q^{\mathrm{last}}_{s,f}[n].
\]

当前帧该指用于组合命令的已提交目标定义为：

\[
\boxed{
\mathbf q^{\mathrm{commit}}_{s,f}[n]
=
\begin{cases}
\widetilde{\mathbf q}_{s,f}[n], & \operatorname{IKValid}_{s,f}[n],\\[4pt]
\mathbf q^{\mathrm{last}}_{s,f}[n-1], & \neg\operatorname{IKValid}_{s,f}[n]\land\operatorname{hasValidIK}_{s,f}[n-1],\\[4pt]
\text{未定义}, & \neg\operatorname{IKValid}_{s,f}[n]\land\neg\operatorname{hasValidIK}_{s,f}[n-1].
\end{cases}
}
\tag{59}
\]

冻结后单指长度异常、单指节点无效、残差超标或求解器错误均适用式（59）：已有历史有效目标就保持，没有历史有效目标就保持未定义。同侧其他合法手指继续求解。

若当前帧因为单指输入无效而没有运行该指求解，则定义该指本帧 \(\operatorname{IKValid}_{s,f}[n]=\mathrm{false}\)，且不存在 \(\widetilde{\mathbf q}_{s,f}[n]\)；式（59）直接进入保持或未定义分支。

历史状态按以下递推更新：

\[
\boxed{
\operatorname{hasValidIK}_{s,f}[n]
=
\operatorname{hasValidIK}_{s,f}[n-1]
\lor
\operatorname{IKValid}_{s,f}[n]
}
\tag{60}
\]

若 \(\operatorname{IKValid}_{s,f}[n]\) 为 true，则 \(\mathbf q^{\mathrm{last}}_{s,f}[n]=\widetilde{\mathbf q}_{s,f}[n]\)；否则若历史目标存在，则 \(\mathbf q^{\mathrm{last}}_{s,f}[n]=\mathbf q^{\mathrm{last}}_{s,f}[n-1]\)。进程启动时所有 \(\operatorname{hasValidIK}_{s,f}=\mathrm{false}\)，且 \(\mathbf q^{\mathrm{last}}_{s,f}\) 未定义。

### 11.2 手侧控制就绪

手侧控制就绪定义为：

\[
\boxed{
\operatorname{ready}_s[n]
\iff
\left(
\bigwedge_{f\in\mathcal F}
\operatorname{lengthFrozen}_{s,f}[n]
\right)
\land
\left(
\bigwedge_{f\in\mathcal F}
\operatorname{hasValidIK}_{s,f}[n]
\right)
}
\tag{61}
\]

因此，即使五指长度都已冻结，只要任一手指尚未获得首次有效 IK 解，该侧就不得输出控制目标。算法不使用默认姿态填补首次失败。

### 11.3 固定 10 维 IK 目标顺序

当当前帧不是整侧几何无效帧且 \(\operatorname{ready}_s[n]=\mathrm{true}\) 时，组合后的、尚未经过软平滑的 IK 主动关节目标为：

\[
\boxed{
\mathbf q_s^{\mathrm{IK}}[n]
=
\operatorname{concat}
\left(
\mathbf q^{\mathrm{commit}}_{s,T}[n],
\mathbf q^{\mathrm{commit}}_{s,I}[n],
\mathbf q^{\mathrm{commit}}_{s,M}[n],
\mathbf q^{\mathrm{commit}}_{s,R}[n],
\mathbf q^{\mathrm{commit}}_{s,L}[n]
\right)
\in\mathbb R^{10}
}
\tag{62}
\]

其标量顺序必须严格为：

```text
0 thumb_roll
1 thumb_abad
2 thumb_mcp
3 index_abad
4 index_pip
5 middle_pip
6 ring_abad
7 ring_pip
8 pinky_abad
9 pinky_pip
```

若当前帧只有部分手指失败但掌坐标仍有效，式（62）使用失败手指的最近有效目标与成功手指的新目标组合。若当前帧整侧几何无效，则不生成新的该侧 10 维 IK 目标，即使该侧此前已经 ready。

式（62）不是重定向节点直接发布给 O10 控制节点的最终目标。已确认的后续顺序为：

\[
\boxed{
\mathbf q_s^{\mathrm{IK}}[n]
\xrightarrow{\text{重定向节点软平滑}}
\mathbf q_s^{\mathrm{soft}}[n]
\xrightarrow{\text{O10 控制节点硬变化率限制}}
\mathbf q_s^{\mathrm{send}}[n]
}
\tag{63}
\]

IK 损失、归一化残差和式（57）的候选有效性均针对软平滑前的 IK 候选。软平滑不反馈修改当前帧的 IK 残差，也不改变下一帧按式（55）使用的上一有效 IK 初值。Phase 1 不对 Rokoko 原始 21 节点或式（39）的 O10 指尖目标做平滑。软平滑函数和状态语义由下一节固定；只有时间常数的具体标定值仍属第 14 节未决项。

### 11.4 基于接收时间的一阶软平滑

定义主动关节索引集合：

\[
\mathcal J=\{0,1,\ldots,9\}.
\]

令 \(q^{\mathrm{IK}}_{s,j}[n]\) 为式（62）中的第 \(j\) 个主动关节目标，令 \(q^{\mathrm{soft}}_{s,j}[n]\) 为软平滑状态和输出。软平滑只处理已经通过单指有效性判定、保持和组合后的 10 维 IK 目标。

令 \(t_s^{\mathrm{recv}}[n]\) 为触发第 \(n\) 帧重定向的 Rokoko 原始帧接收时间。令 \(\pi_s(n)\) 表示第 \(n\) 帧以前最近一次实际更新该侧软平滑状态的帧编号，则：

\[
\boxed{
\Delta t_s[n]
=t_s^{\mathrm{recv}}[n]-t_s^{\mathrm{recv}}[\pi_s(n)]
}
\tag{64}
\]

正常更新要求 \(\Delta t_s[n]\) 有限且严格大于 0。时间戳重复、倒退或非有限时，本次不更新软平滑状态、不发布该侧新目标并报告时间异常。时间基准使用原始帧 ROS 接收时间，不使用时基未确认的 Rokoko `source_timestamp`，也不使用 IK 回调执行完成时的墙钟时间。

为每个主动关节配置时间常数 \(\tau_j>0\)，单位为秒；左右手相同关节语义共享同一组 \(\boldsymbol\tau=(\tau_0,\ldots,\tau_9)^\mathsf T\)。定义：

\[
\boxed{
\alpha_{s,j}[n]
=1-\exp\left(-\frac{\Delta t_s[n]}{\tau_j}\right)
}
\tag{65}
\]

以及：

\[
\boxed{
q^{\mathrm{soft}}_{s,j}[n]
=
\left(1-\alpha_{s,j}[n]\right)
q^{\mathrm{soft}}_{s,j}[\pi_s(n)]
+\alpha_{s,j}[n]q^{\mathrm{IK}}_{s,j}[n]
}
\tag{66}
\]

这是按实际输入间隔更新的一阶低通滤波。\(\tau_j\) 越小，跟随越快、抑制噪声越弱；\(\tau_j\) 越大，平滑越强、跟随延迟越大。具体数值必须通过离线样例、合成噪声和未来真实数据标定。

某侧第一次达到 ready 并在第 \(n_0\) 帧产生完整 10 维 IK 目标时，不存在 \(\pi_s(n_0)\)，初始化为：

\[
\boxed{
\mathbf q_s^{\mathrm{soft}}[n_0]
=\mathbf q_s^{\mathrm{IK}}[n_0]
}
\tag{67}
\]

不得假定零关节状态或关节范围中点是实体手当前姿态，并用它虚构软平滑历史。首次命令相对实体手当前状态的安全过渡属于 O10 控制节点硬变化率限制的职责。

单指当前帧失败但已有历史有效 IK 时，式（59）使该指的软平滑输入保持为上一有效 IK 目标；式（66）继续让已有软状态靠近这个合法目标，不使用失败候选、不冻结在中间状态、也不重置滤波器。同侧其他成功手指照常更新。

整侧当前帧无效或输入 stale 时，不调用该侧软平滑器、不修改其状态、不发布新目标。stale 恢复时不得把跨越整个断流期的时间直接代入式（65）；恢复过程由第 11.5 节固定。

式（66）只提供自然度平滑，不提供最大变化率保证；O10 控制节点仍必须在其后施加独立且不可绕过的硬限制。

### 11.5 stale 恢复确认与有界恢复

进入 stale 时，保存重定向节点最后一次发布的 10 维软平滑目标：

\[
\boxed{
\mathbf q_s^{\mathrm{soft,hold}}
=\mathbf q_s^{\mathrm{soft}}[\pi_s(n_{\mathrm{stale}})]
}
\tag{68}
\]

其中 \(n_{\mathrm{stale}}\) 表示该侧被判为 stale 的时刻所对应的输入状态，\(\pi_s(n_{\mathrm{stale}})\) 是 stale 前最后一次实际更新软平滑器的帧。stale 期间停止发布、不更新软平滑状态、不推进其时间基准，并将恢复计数器清零；既有操作者 `armed` 锁存按 O10 控制契约保留。

定义恢复帧有效性：

\[
\boxed{
\begin{aligned}
\operatorname{RecoveryFrameValid}_s[n]
\iff{}&
\operatorname{RawSideValid}_s[n]
\land\operatorname{PalmFrameValid}_s[n]\\
&\land
\left(\bigwedge_{f\in\mathcal F}
\operatorname{CurrentLengthValid}_{s,f}[n]\right)\\
&\land
\left(\bigwedge_{f\in\mathcal F}
\operatorname{IKValid}_{s,f}[n]\right).
\end{aligned}
}
\tag{69}
\]

其中 \(\operatorname{RawSideValid}\) 表示该侧当前 21 节点原始帧完整且合法；\(\operatorname{PalmFrameValid}\) 表示当前人体解剖学掌坐标可构造；\(\operatorname{CurrentLengthValid}\) 表示当前指链长度通过冻结尺度检查。恢复期式（69）要求五指**当前帧的 IK 候选**全部有效，不能用 stale 前或普通单指保持分支中的历史目标冒充恢复证据。

定义：

- \(K_{\mathrm{recover}}\in\mathbb N\)：恢复所需最少连续有效帧数；
- \(T_{\mathrm{recover,min}}>0\)：恢复序列所需最短接收时间跨度；
- \(c_s[n]\in\mathbb N_0\)：截至第 \(n\) 帧的当前连续恢复有效帧数；
- \(n_s^{\mathrm{start}}\)：当前连续恢复序列第一帧编号。

计数器递推为：

\[
\boxed{
c_s[n]
=
\begin{cases}
c_s[n-1]+1,&\operatorname{RecoveryFrameValid}_s[n],\\
0,&\neg\operatorname{RecoveryFrameValid}_s[n].
\end{cases}
}
\tag{70}
\]

当计数从 0 变为 1 时设置 \(n_s^{\mathrm{start}}=n\)。当前恢复序列持续时间为：

\[
\boxed{
D_s[n]
=t_s^{\mathrm{recv}}[n]-t_s^{\mathrm{recv}}[n_s^{\mathrm{start}}]
}
\tag{71}
\]

输入恢复成立当且仅当：

\[
\boxed{
\operatorname{InputRecovered}_s[n]
\iff
c_s[n]\ge K_{\mathrm{recover}}
\land
D_s[n]\ge T_{\mathrm{recover,min}}
}
\tag{72}
\]

恢复序列中的接收时间必须有限且严格递增。任一无效帧、再次超时、重复时间、倒退时间或非有限时间均令 \(c_s[n]=0\)，丢弃当前恢复候选序列并返回 stale 暂停。

恢复确认期间允许执行人体归一化和五指 IK；首次 IK 继续以 stale 前各指最后有效 IK 为 warm start。所有当前结果只写入与正常运行历史隔离的恢复候选区：不得覆盖 \(\mathbf q^{\mathrm{last}}_{s,f}\)、\(\mathbf q_s^{\mathrm{soft,hold}}\) 或正常软滤波时间状态，也不得发布控制目标。只有式（72）成立时，最后一帧完整有效恢复候选才成为后续实时 IK 输入。

恢复成功时执行以下有界切换：

1. 保持 \(\mathbf q_s^{\mathrm{soft}}=\mathbf q_s^{\mathrm{soft,hold}}\)，不跳到恢复候选；
2. 将软滤波上一更新时间重置为满足式（72）的恢复成立帧接收时间，断流期不参与式（64）、式（65）；
3. 恢复后的第一条软目标仍发布 \(\mathbf q_s^{\mathrm{soft,hold}}\)；
4. 从下一帧开始，以恢复后的相邻合法帧接收时间差执行式（65）、式（66），由原一阶低通逐步追赶实时 IK 目标；
5. 所有恢复输出继续经过 O10 控制节点的最终硬变化率限制。

Phase 1 不增加第三套恢复插值器。低通滤波负责降低恢复突兀，硬变化率限制负责最终速度边界。输入恢复只改变输入新鲜度状态，不创建或修改 `armed`，也不能清除锁存控制故障。

### 11.6 时间戳与可观测状态

组合 O10 目标的 `JointState.header.stamp` 沿用触发本次计算的 Rokoko 原始手部帧接收时间，不改成 IK 完成时间。这样可以计算端到端数据年龄。

每侧通过 `rokoko_omnihand_msgs/msg/RetargetingState` 发布完整状态，五指数组顺序统一为 \((T,I,M,R,L)\)。消息字段、阶段枚举、长度/IK 状态、残差可用位、求解器返回码、恢复进度和三个时间语义由《手部重定向状态 ROS 接口契约》固定。IK 完成时间、求解耗时、评估次数和终止原因只进入状态，不写入控制目标时间戳；不可用残差必须以可用位 false 和 NaN 表达，不能用 0 冒充。

输入 stale 时，算法停止产生新命令并报告 `stale=true`，让下游保持最后目标。恢复严格遵守式（68）至式（72）及第 11.5 节的有界切换。stale 不自动清除已经成功的操作者 `armed` 锁存，但输入恢复也不能创建或恢复一个已经为 false 的 `armed`；最终运动许可同时受 O10 控制契约约束。

## 12. 每侧逐帧确定性流程

以下顺序是本文算法的规范性流程。一侧的每个输入事件独立执行；另一侧拥有完全独立的长度窗口、冻结值、IK 历史和 ready 状态。

### 12.1 启动阶段

1. 从 ROS 包索引解析专用 O10 模型资产包的安装路径，验证 provenance 来源版本与逐文件 SHA-256，并加载对应手侧的固定 URDF；不得使用用户目录或参考源码仓库绝对路径。
2. 以 Pinocchio 零关节状态计算式（28）至式（37）的机器人几何常量。
3. 以 Pinocchio `mimic=false` 显式忽略 URDF 线性 `mimic`，断言 \(n_q=n_v=16\)；再由严格 Coupling Loader 加载同资产版本、对应手侧 MJCF 的 6 条耦合系数，构造式（41）至式（47）的映射。
4. 校验机器人几何、关节名称、主动关节顺序、关节限位、tip frame 和耦合输出。
5. 将每根手指长度状态置为 `collecting`，IK 状态置为 `uninitialized`，`ready=false`，不产生启动命令。

### 12.2 长度收集阶段

对第 \(n\) 帧：

1. 验证构造掌坐标所需节点并执行第 3 节；失败则整侧帧结束。
2. 对每根手指验证节点并计算式（14）、式（15）。
3. 合法长度样本加入该指独立窗口；非法手指不推进其窗口。
4. 对已形成的窗口计算式（17）、式（18），执行式（19）、式（20）。
5. 某指达到稳定条件时按式（21）冻结，之后不再更新该冻结值。
6. 式（23）成立之前不生成 O10 目标、不运行 IK、不输出该侧命令。

### 12.3 正常重定向阶段

同侧五指长度冻结后，对第 \(n\) 帧：

1. 构造人体掌坐标；失败则整侧不输出新命令。
2. 对每指计算当前链长并执行式（24）、式（25）的冻结尺度检查。
3. 对每根当前输入合法的手指计算式（26）、式（27）和式（39）的 O10 指尖目标。
4. 依据式（55）选择初值，独立求解式（53）。
5. 依据式（57）判定候选，而不是依据优化器停止文字直接判定。
6. 依据式（59）提交新目标或保持该指上一有效目标。
7. 依据式（61）判断该侧是否 ready。
8. ready 且当前帧不是整侧几何无效帧时，按式（62）生成 10 维 IK 目标，依据式（64）至式（67）完成重定向软平滑后发布；否则不发布新命令。
9. 无论是否发布控制目标，都更新可观测状态和诊断。

## 13. 算法不变量

实现必须始终保持以下不变量：

1. **坐标一致性**：式（48）的实际指尖和式（39）的目标指尖必须同时表达在同一规范掌坐标 \(R_s\) 中。
2. **人体旋转来源唯一**：人体掌朝向只由位置几何构造；`Hand.rotation` 不参与本文算法。
3. **共享方向映射**：同侧五指共享唯一的 \(\mathbf A_s\)，不存在 \(\mathbf A_{s,f}\)。
4. **尺度冻结**：\(\overline{\ell}^{\,h}_{s,f}\) 一旦冻结，在进程结束前不改变。
5. **模型来源一致**：\(\mathbf a_{s,f}\)、\(\ell^r_{s,f}\) 和 \(\mathbf A_s\) 来自同一个对应侧固定 URDF。
6. **主动变量唯一**：优化器只能修改 10 个主动关节；被动关节只能由 \(\mathbf G_{s,f}\) 派生。
7. **完整 FK**：所有损失和残差均由耦合后的完整关节状态计算。
8. **损失无量纲**：基础损失严格等于机器人指链归一化残差的平方。
9. **停止不等于有效**：优化器终止原因与式（57）的候选有效性分离。
10. **失败不污染历史**：无效候选不得覆盖 \(\mathbf q^{\mathrm{last}}_{s,f}\)。
11. **首次失败不补位**：五指均至少成功一次以前，不输出该侧命令。
12. **单指故障隔离**：掌坐标有效时，单指失败只保持该指，不阻断同侧其他手指。
13. **整侧几何故障隔离**：掌坐标退化时，整侧当前帧不输出，但不影响另一侧。
14. **输出维度和顺序固定**：软平滑的输入和输出始终使用式（62）规定的 10 个主动关节顺序。
15. **接收时间可追踪**：控制目标继承输入接收时间，求解完成时间另行诊断；Rokoko 源时间不冒充 ROS 接收时间。
16. **软平滑不改变 IK 语义**：IK 残差、候选有效性和下一帧 warm start 均使用软平滑前的有效 IK 目标。
17. **软平滑使用数据时间**：正常连续输入只用相邻实际滤波更新帧的 ROS 接收时间差；无效帧和 stale 不推进滤波状态。
18. **资产来源可复现**：运行模型只来自 ROS 安装空间中通过来源、哈希和结构校验的专用资产包，不能回退到外部绝对路径。
19. **URDF 几何与 MJCF 耦合分工固定**：URDF 以 `mimic=false` 提供 16 维完整几何；MJCF 只经严格解析提供 6 条非线性耦合，二者必须属于同一 provenance 版本。

## 14. 当前尚未确定、不得写死的边界

以下问题会在后续逐项封装，不属于本文已经确定的算法：

1. 优化器内部收敛阈值及 \(N_{\mathrm{eval},\max}\)、\(T_{\max}\) 的具体数值；
2. \(N\)、\(K\)、\(\tau_{\rho,f}\)、\(\varepsilon_y\)、\(\varepsilon_x\)、\(\varepsilon_\ell\)、\(\varepsilon_{\mathrm{length},f}\)、\(\varepsilon_{\mathrm{IK},f}\) 的标定值；
3. 重定向节点软关节平滑时间常数 \(\tau_j\) 的具体标定值；
4. O10 控制节点最终关节变化率 \(\dot q^{\max}_{s,j}\)、时间额度 \(\Delta t^{\mathrm{credit}}_{\max}\) 和启动反馈新鲜度的具体标定值；
5. stale 自动恢复所需 \(K_{\mathrm{recover}}\) 和 \(T_{\mathrm{recover,min}}\) 的具体标定值；
6. 上游 O10 模型资产的再分发许可确认；在此之前不得把参考仓库模型文件正式复制进本仓；
7. ROS 消息包名、Topic 名称、状态消息定义及 QoS 的最终 spec；
8. 真机验收阈值；当前没有真机实验条件。
