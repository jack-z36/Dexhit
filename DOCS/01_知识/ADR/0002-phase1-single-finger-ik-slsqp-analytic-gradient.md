# Phase 1 单指 IK 使用 SLSQP 与解析耦合梯度

Phase 1 的每个单指 IK 使用 NLopt `NLOPT_LD_SLSQP`，优化变量仅为该指主动关节，硬约束为主动关节上下界。目标函数为机器人指链长度归一化的指尖位置残差平方。

运行时梯度由两部分按链式法则组成：Pinocchio 提供指尖对完整指链状态的平移雅可比；项目的 Coupling Adapter 根据与被动关节求值相同的 MJCF 多项式系数，提供完整指链状态对主动关节的解析耦合雅可比。项目不以简单抽取主动关节列代替耦合求导，也不在实时路径使用数值差分。

SLSQP 负责搜索方向、内部曲率近似、线搜索和边界内步进；项目负责损失、梯度、上下界、初值、停止条件及优化后候选有效性判定。首次初值使用关节范围中点，后续使用上一有效解 warm start。该后端是局部优化器，不承诺全局最优；Phase 1 不采用全局搜索或多初值搜索。

中心数值差分只作为离线测试的独立参考，用于验证左右手、五指以及左右拇指不同耦合多项式下的解析梯度。具体收敛阈值、最大评估次数、最大求解时间、差分步长和测试容差不由本 ADR 写死，必须通过离线实验与性能基准确定。
