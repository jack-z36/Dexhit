# stale 恢复使用连续整侧验证和既有两级平滑

一侧 Rokoko 输入 stale 时，重定向节点停止发布，冻结软平滑状态和时间基准，并保存 stale 前最后软目标。既有操作者授权保留，O10 控制入口保持最后实际发送命令。

恢复不能由单帧触发，必须同时满足可配置的最少连续有效帧数和最短接收时间跨度。每个恢复证据帧必须具有合法完整的该侧原始骨架、可构造的人体掌坐标、五指当前冻结尺度检查全部通过，并且五指当前 IK 候选全部有效；普通运行的历史单指保持不能充当恢复证据。任何失败帧或时间异常都会清零恢复序列。

恢复确认期间的 IK 结果只进入独立候选区，不修改正常 IK 历史、软平滑状态或控制输出。恢复成立时保留 stale 前软目标，重置软滤波时间，第一条恢复输出仍为保持目标；从下一帧开始使用既有一阶低通追赶实时 IK，所有输出继续经过 O10 控制节点的硬变化率限制。

Phase 1 不增加第三套恢复插值器。输入恢复只改变数据新鲜度，不能创建或修改操作者授权，也不能清除锁存故障。具体连续帧数和最短观察时间由样例及真机数据标定。
