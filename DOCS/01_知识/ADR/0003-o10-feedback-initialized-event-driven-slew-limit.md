# O10 最终命令使用反馈初始化的事件触发硬限速

O10 控制入口对左右手独立施加最终且不可绕过的逐关节命令变化率限制。限制器以本机单调时钟计算相邻实际发送命令的时间，使用可配置的单次最大时间额度防止停顿积累无限移动额度，并以最后实际发送命令作为运行基准。

控制入口保持事件触发：每收到一条合法的新鲜上游目标，最多发送一条受限命令；没有新目标时不创建定时器继续追赶旧目标。这样使上游断流立即停止产生新动作，并与系统的 stale 保持语义一致。

每侧首次允许发送以前，硬限制器必须由硬件 Adapter 在不先改变手姿态的条件下独立读取的新鲜、合法 10 维真实主动关节反馈初始化。首个目标同样受限。项目不使用零位、关节范围中点、首个目标或跨进程缓存猜测起点；无法获得合格反馈时，该侧保持未初始化并拒绝发送命令。

当前厂商 ROS 节点只保证位置命令触发位置回读，不能满足上述无动作启动读取；本地 SDK 1.1.8 动态库存在 `GetAllActiveJointAngles()`。正式实现必须在硬件 Adapter 边界补足独立启动读取能力，不新增第四个稳定功能节点。当前项目控制入口仍是校验后直通，因此本 ADR 是已接受的目标设计，而不是已完成能力。

具体每关节最大变化率、最大时间额度和反馈新鲜度阈值必须依据官方资料、离线测试及真机实验标定，本 ADR 不写死数值。
