# O10 真机运动需要逐侧显式操作者授权

实体 O10 运动不能由“数据和算法已经就绪”自动触发。每个逻辑手侧独立维护操作者 `armed` 锁存，进程每次启动时均为 false；只有操作者在真实启动反馈、重定向就绪、输入新鲜且无锁存故障等前置条件当前成立时显式请求，才可置为 true。

失败的使能请求不会排队或等待未来自动生效，使能成功本身也不产生启动命令。真正的运动许可是 `armed` 与所有技术前置条件的逻辑合取，不是另一个可写开关。

操作者可随时解除单侧使能。解除使能立即停止产生新的官方命令，但不自动张手、回零、追赶旧目标或断开驱动，也不等同于硬件急停。左右手授权与运动路径相互独立。

普通输入 stale 暂停运动但不自动清除既有 `armed` 锁存；输入满足后续恢复条件且操作者未解除使能时，允许通过有界过渡恢复。数据恢复不能绕过或重新创建操作者授权。逐侧授权、解除授权和清除故障采用独立 ROS Service，并返回机器可读结果与操作后的控制状态快照。
